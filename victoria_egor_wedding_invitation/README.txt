СВАДЕБНОЕ ПРИГЛАШЕНИЕ — ВИКТОРИЯ & ЕГОР
Дата: 07.08.2027
Место: Банкетный зал «Александрия»

Как открыть:
1. Распакуйте ZIP-архив полностью.
2. Откройте index.html в браузере.
3. Для отправки гостям разместите всю папку на статическом хостинге (например, GitHub Pages / Netlify).

В папке assets находятся фотографии и 45-секундный музыкальный фрагмент.

Промежуточный экран с персональным обращением удалён: после нажатия на сургучную печать конверт открывается, и сразу появляется основное приглашение.

Важно:
- Музыка начинает играть после нажатия «Открыть приглашение»; если браузер блокирует воспроизведение, используйте круглую кнопку с ноткой.
- Таймер считает до 07.08.2027 15:00 по местному времени устройства гостя.
- Ссылка «Как добраться» ведёт на присланную Яндекс.Карту.
- Формы RSVP, чат гостей и контакты не добавлены по вашему решению.
